## Integration requirements

Keep source field names, IDs, route parameters, real acting identity, grants, source scopes and independent-review commands authoritative. Style markers are not permission checks. Compact layout remains a desktop fine-pointer preference. Maintain touch control geometry independently of stored density.

Retain the search entry guard when integrating global shortcuts. Search must not replace a saving dialog or silently discard an edited decision. Continue through the canonical modal's Keep editing/Discard flow. Live selection announcements use plain text and preserve link semantics.

The phone drawer must release its previous inert/role values and body scroll lock on every exit. Restore the opener before opening search so the search dialog can later return focus to a visible element. Within the drawer, normal focus scrolling keeps offscreen destinations reachable. Desktop resize does not focus the hidden phone opener.

Preserve the complete canonical records beneath all visual changes: Branch KRI answers/conditional details, accepted loss/receipt/reversal values, response cycles and named reviewers, document versions, vendor activation conditions, privacy snapshots, reporting populations/currencies and frozen packs.

## Production boundary

This is a synthetic local implementation reference. Production services must bind actual identity/tenant, enforce exact scope and independence, protect history and implement concurrency. Durable Documents, safe conversions, authenticated external requests and real notification delivery remain server work. UI polish does not imply those services are deployed.
