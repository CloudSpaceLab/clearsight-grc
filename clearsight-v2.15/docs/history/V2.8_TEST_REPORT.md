**Total: 60 model/workflow checks and 68 route/action checks.**

The integrated suites execute application modules in Node with a substituted browser/DOM shell. Governance's policy suite additionally isolates its fixtures. Route checks verify generated markup and action registration; they do not establish browser pointer, focus or layout behaviour.

The standalone's concatenated JavaScript compiles and its CSS/scripts are inline. Module entry points and standalone are built from the same sources. The package manifest validates exact file bytes.

## Browser limitation

Chromium could not launch because socket creation returned `Operation not permitted`. The supported cloud browser rejected the local-file URL protocol. These restrictions were not bypassed. Browser workflow suites are included, but no V2.8 layout, screenshot, mobile overflow, keyboard traversal, download, native PDF-viewer, print or storage-reload pass is claimed.

Older screenshots and browser results are historical V2.7 or earlier evidence, not results for this release. The prior report is retained under `docs/history/V2.7_TEST_REPORT.md`.

## Remaining integration gate

Run the browser suites in a supported browser and inspect wide, tablet, mobile and dark layouts, keyboard/focus behaviour, downloads and print output. Then map the UI to the production authenticated services. This release has no deployment, live notification delivery, background escalation execution or server authorization.

The workbook contains operational questions but no approved risk thresholds. Rules must be approved as organizational policy before operational use. Real source branch responses were not copied into the demonstration data.
