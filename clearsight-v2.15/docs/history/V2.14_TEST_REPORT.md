## Browser acceptance boundary

No browser was retried after the previously observed process/socket and local-file access restrictions. These checks do **not** establish computed layout, actual CSS cascade appearance, native focus/`inert` behavior, screen-reader announcements, touch ergonomics, text zoom, browser storage, native file downloads, original PDF display or print-to-PDF pagination.

Review supported browsers at 320/390/768/1024/1440 px, light/dark and comfortable/compact. Exercise long names and source text, editable tables, permission/empty states, short viewports, drawer→search→close, unsaved/busy review dialogs, document previews/originals, external save/resume and print. Historical screenshots and earlier release outputs remain historical evidence only.

## Reproducibility and package integrity

`build.py` reconstructs the deliverables from the shared sources. `MANIFEST.json` covers all release files except itself and Python bytecode caches; `python3 verify_reference.py` verifies the untouched release. Packaging checks archive CRCs and confirms that the standalone bytes inside the ZIP match the separate HTML deliverable. Rebuilding or rerunning tests can change covered files.
