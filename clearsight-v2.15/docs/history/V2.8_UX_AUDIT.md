## Source findings

The supplied folder contains `Ops Risk (2).zip`, including `Branch KRI .xlsx`, sheet `Branch KRI November '25`. Columns A–C identify directorate, region and branch; D–BB contain 51 questions; BC contains CCO/CCM remarks. Generic trailing columns and a hidden application-metadata sheet were not treated as risk questions.

The source includes non-numeric responses in numeric columns, inconsistent CCTV state/count and a card-printer follow-up with an outdated item-number reference. The UI uses typed inputs and a stable semantic dependency. `BRANCH_KRI_MAPPING.json` preserves question/column provenance. Actual source branch responses were not imported into the synthetic demo.
