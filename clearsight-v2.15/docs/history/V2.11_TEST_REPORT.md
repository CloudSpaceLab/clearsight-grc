## Running

Run `python3 build.py`, then each `node tests/<script>` listed above. Suffixes v28/v29/v210 identify inherited contracts intentionally exercised against the current sources. Result JSONs contain per-check outcomes; `tests/validation-summary.json` is the current authoritative summary.

Run `python3 verify_reference.py` on an untouched release. Builds/tests can alter manifest hashes; regenerate intentionally for a later release.

## Limits and browser handoff

Browser execution had previously been blocked by process/socket restrictions and cloud local-file navigation policy. It was not retried or bypassed. The source-level interaction tests use replacement elements/events and do not prove native focus, hash history, inert support, actual keyboard/screen-reader behavior, responsive layout, browser storage/download or print. Those remain targeted observation gates in an allowed browser environment. Historical screenshots and browser result files do not certify this release.

The package uses synthetic local records. It does not certify production server authorization, concurrent writes, secure hosting, real supplier invitations, notification delivery, background escalation or enterprise integrations.
