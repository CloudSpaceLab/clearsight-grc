## Independent findings resolved

An independent source review reproduced two external defects: optional/hidden mixed-grid clearing could remove protected technical cells, and final reference-byte reading could outlive an export-permission revocation. Both were fixed and independently reverified with the original reproductions. Additional integration fixes pin program scope in canonical publication, retain typed action-source authority, and keep blank optional human grids independent of existing technical observations.

## Browser acceptance boundary

No browser was launched or used for V2.12 validation. Previously observed Chromium process/socket restrictions and the cloud browser's local-file navigation restriction were not retried or bypassed. Actual-source execution with substituted DOMs does not validate rendered layout or native browser behavior.

Still requiring acceptance in supported browsers: desktop/mobile layout and overflow; keyboard/screen-reader navigation; native dialog, focus and history behavior; IndexedDB and session fallback; original-file download; native PDF display; Office preview/fallback; recipient draft save/resume and file return; and print output. No full fidelity Office-rendering or hosted authentication/email/OTP claim is made.
