## Review the changes

1. Begin at My workspace and use Display preferences to compare light/dark and comfortable/compact layouts.
2. Open Frameworks and follow adoption; inspect requirements, quality settings and assigned people.
3. Open the live form builder and inspect question editing, table columns, required/source/validation controls and preview.
4. Inspect risk/control/RCSA records, the loss register, indicator observations and branch return catalog. Compare saved facts with proposed decisions.
5. Follow a privacy processing record or case through its capture and review stages. Inspect integration/check results with their real source statuses.
6. In a dialog with unsaved input, invoke search. Keep editing or deliberately discard through the existing decision. Search waits while a save is pending.
7. At phone width, open navigation, use its close button/Escape, select a destination or open search with Ctrl/⌘K. Check return focus and preserved page context.

Use actors with the appropriate existing grants or named responsibilities. My access explains restrictions. Choosing a different display density or responsibility lens never grants authority.
