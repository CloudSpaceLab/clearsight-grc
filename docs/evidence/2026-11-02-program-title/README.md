# Program title weight review

The approved Program reference uses a bold title. The runtime inherited a normal
weight from the base styles, weakening the record hierarchy. The scoped change
sets the existing Program title to 700 without changing the type scale or tokens.

The retained before and after captures use the evidence build's Program fixture
at 1440×900 and 390×844. The corrected title was also inspected in dark mode at
both sizes. The phone and desktop checks showed no horizontal page overflow.
The fixture does not establish visual parity or operational acceptance for the
Program screen; the remaining cutover gates are in the existing status ledger.
