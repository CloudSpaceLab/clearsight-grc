# PDF preview fallback evidence

On 21 November 2026, headless Chrome rendered the Documents workspace at widths 1440, 768 and 390 pixels. An evidence-only response supplied a synthetic PDF and the browser's PDF-viewer capability was set to false. Each render showed the preview limitation and an available download action; no document content request or preview frame occurred, and document-level horizontal overflow was absent. The desktop and mobile renders were visually inspected. The full-page mobile image includes a capture artifact from the sticky header after the details panel scrolls into view.

This evidence covers an authorized sample document in light mode. It does not prove live permissions, actual download completion, other file types, dark mode or full screen acceptance. The focused Documents tests also cover the restricted unscanned case: no download is offered when the occurrence does not permit one.
