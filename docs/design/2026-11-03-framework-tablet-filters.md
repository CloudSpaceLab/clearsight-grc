# Framework Library tablet filters

The approved Framework HTML puts search on a full-width row above the filters
at tablet widths. The runtime squeezes search and both supported filters into
one row at 768px. Use the existing responsive filter grid to put search above
the content-rights and jurisdiction controls at 701–820px; a disclosed
jurisdiction form spans the full row. Keep the current phone replacement,
search scope, cursor, filter reset, explicit edition selection and permissions.

Compare the source and runtime at all approved widths in both runtime themes.
Test active filters, jurisdiction edit and recovery, 44px controls, keyboard,
long content and the breakpoint edges. Do not introduce the source's unsupported
industry selector or sample editions. This is partial V2 integration.
