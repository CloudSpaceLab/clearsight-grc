# Vendor portfolio phone navigation

The approved Vendor HTML retains its five-destination tab strip on phone. The
runtime replaces that strip with a selector below 761px. Use the shared Tabs
contract for the same five route-backed destinations at every width, with a
single horizontally scrollable row on narrow screens and automatic reveal of
the selected tab. Preserve 44px targets, keyboard navigation, browser history,
draft locking and the separate relationship workspace's navigation.

Compare source and runtime at the five approved widths in both runtime themes,
and test every route, keyboard and touch activation, selected-tab reveal,
record entry/return, denied and partial states and long names. The source's
illustrative counts and unsupported controls are not runtime facts. This is
partial V2 layout integration; whole-screen acceptance remains separate.
