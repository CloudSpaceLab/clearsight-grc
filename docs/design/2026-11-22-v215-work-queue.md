# Work and approvals — v2.15 adaptation

The workspace follows the v2.15 sequence of work views, compact assignment summary, search and a structured work register. The existing actor-scoped queue, real Matter destination, response-review and form-approval readers remain the only work sources. No additional queue, decision command, completed-work population or unsupported filter was introduced.

The four summary values come from the existing `SOURCE_SNAPSHOT` assignment-count endpoint and are displayed only after its tenant, legal entity, principal, timestamp and count relationships are verified. They cover all workflow assignments rather than only search results and display their own as-of time. Missing, invalid or wrong-actor counts are unavailable rather than zero. The queue page has a separate timestamp and keeps its existing cursor and access checks. Due indicators use the queue receipt timestamp and a valid stored UTC deadline; an invalid deadline has no urgency classification.
