# Program first-viewport notices

Program review and assignment notices precede the source-matched section tabs.
Repeated descriptions of visible interface content crowd those controls and do
not help the owner resolve the condition. Retain the specific unavailable or
stale state, command limitation and retry action; remove interface narration.
Loading notices name the check in progress. No command or authorization state
changes. Verify degraded, stale, loading and available workflows, including
keyboard recovery and responsive rendering.

The degraded-state render also exposed 25px-high retry buttons. Give those
existing notice actions a 44px minimum height for touch without changing their
command or focus behavior.
