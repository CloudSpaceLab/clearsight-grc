# Program projection status

The Program register labels explicitly stale or version-mismatched projections “Out of date.” It labels a status “Unknown” when the source does not provide the required version, state, freshness or generated-time fields. A valid current projection retains its supplied state label and timestamp. Missing or invalid counts display “Unknown”; a recorded zero remains zero.

Prior sample Program renders are in `docs/evidence/2026-11-21-v215-secondary-actions/`. New synthetic stale, incomplete and current examples are in `docs/evidence/2026-11-21-v215-program-projection/` at 1440, 768 and 390 pixels. The browser check verifies those states and absence of horizontal overflow. The 1440- and 390-pixel renders were inspected. These examples do not establish backend data quality, tenant authorization, dark-theme behavior or complete Program screen acceptance. The broader legacy projection suite remains until its other summary and drill workflows are available.

The active register tests also check that a recorded actor-visible issue count remains visible when assessment status is unknown, and that a page with a next cursor is not presented as an enterprise total. The legacy `ProgramsProjectionTruth.test.tsx` remains unresolved: it additionally requires a bounded assessment summary, a separately displayed evidence-check count, and direct navigation to a Program's issues. Those requirements have not been replaced by the current tests. An assessed-state filter backed by the server query and a count of loaded records are now covered separately; see `docs/design/2026-11-21-v215-program-filter.md`.
