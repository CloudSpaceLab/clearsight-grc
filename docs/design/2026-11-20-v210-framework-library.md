# V2.10 Framework library

The framework library lists published catalog editions for the selected jurisdiction, using the existing scoped catalog endpoint and its ID cursor. Search applies only to loaded editions. The selected edition shows publication source and rights and retrieves licensed clause references with a bounded cursor through the authenticated catalog read. HTTPS source links exclude embedded credentials. Publication is a catalog fact and does not establish program adoption or compliance.

The selected edition can be proposed to an existing program after the current Program and operation authority are read and their versions match. A pending proposal can be approved or rejected only for an exact matching edition when the current Program operation permits it. Commands carry the current Program version and never send an actor ID. A lost response prevents automatic retry; the Program must be checked. The server remains responsible for current authority, scope, reviewer separation and transaction enforcement. New Program creation, clause mapping and manual-question overrides are not part of this slice.
