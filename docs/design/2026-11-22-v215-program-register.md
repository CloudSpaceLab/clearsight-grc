# Programs register — v2.15 adaptation

The Programs register follows the v2.15 page sequence: heading and authorized creation action, four compact measures, scoped search and status controls, then a dense table with explicit record actions. The existing Program summary API, actor scope, filter URLs, pagination, freshness checks and visible-issue drill remain unchanged. The table does not invent assessment percentages or framework names absent from this response.

The measures describe only the currently loaded Program records. The first measure states when further pages are available; the other cards identify their loaded-Program population. An invalid or missing issue count makes the issue measure unknown. The out-of-date measure counts confirmed stale snapshots; an explicit unknown-assessment measure is shown separately. Status colors are paired with text and do not turn a stale or incomplete snapshot into a current assessment.
