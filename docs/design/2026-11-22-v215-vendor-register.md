# Vendor register: v2.15 adaptation

The current register omitted the reference's posture strip, lifecycle navigation and structured engagement panel. This change uses the v2.15 `clearsight-v2.15/vendors.html` reference (SHA-256 `cb9a68a90ecb0ab4f134920f511148eb4ca4d8a26bc171cfc088510aa82a3952`) for the page hierarchy. Counts and filters use only authorized loaded relationship records; the interface identifies that limit and keeps cursor loading available. Renewal dates and lifecycle statuses come from each stored relationship. The creation and selected-relationship workflows retain their existing authority and scope checks.

The synthetic reference capture at 1440px and isolated runtime captures at 1440, 1280, 1024, 768 and 390px are in `docs/evidence/2026-11-22-v215-vendor-register/`. The initial 768px render compressed table cells, so the register now switches to stacked rows at 900px; the corrected captures have no horizontal overflow. The fixture uses mocked data and a simplified shell and does not prove live authorization, production data or whole-screen acceptance. The source's onboarding banner and unavailable assessment/document tabs are not reproduced as enabled controls. Further paired full-shell, dark-theme and accessibility review remains required.
