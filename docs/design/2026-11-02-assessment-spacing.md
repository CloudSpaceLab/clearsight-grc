# Assessment heading and work spacing

The pinned Assessment source uses a strong title and places local views directly
after the record header. The internal capture form adds a second top margin on
top of the workspace gap, separating the working views from the header and
pushing questions lower. Remove the duplicate margin and use the source's bold
heading while retaining verified request status, due date, section progress and
the existing response editor. External capture and compact sheets are outside
this scoped rule. Compare source and runtime at five approved widths in both
runtime themes, including long titles, keyboard and response state. The Excel
mapping and full Assessment acceptance remain open.
