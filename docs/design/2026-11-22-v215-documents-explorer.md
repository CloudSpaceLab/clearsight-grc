# Documents explorer — v2.15 adaptation

The submitted-document inventory now uses the v2.15 document explorer anatomy: the existing review views remain above an explorer rail and compact register. The rail filters by the file types supported by the existing authorized inventory query. The register separates the file, form and submission context and retains the current detail, preview and download actions. It does not invent folders, classifications, counts, upload or management actions that the current backend does not provide.

On narrow screens the rail is replaced by the existing file-type selector and each register row becomes a labelled two-column record. When the detail panel opens, the list also uses this compact layout. Exact vendor and response scope, search, cursor pagination and selected-file preview retain their existing contracts.
