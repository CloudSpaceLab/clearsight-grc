# Loss ledger heading alignment

The approved operational-risk HTML places the Loss ledger heading and Record
loss action side by side on phone. The embedded runtime lets the heading's
intrinsic width consume the row, pushing the action and first record down.
Allow the heading to shrink beside the existing button, wrap long scope text,
and retain a stacked fallback where space is insufficient. Keep the authorized
entry workflow, real scope and filters unchanged. Compare the original and
runtime at the five approved widths, exercise small widths and long scope text,
and verify the action, filter and selected-record paths. This is partial V2
integration and does not establish operational acceptance.
