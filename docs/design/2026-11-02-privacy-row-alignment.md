# Privacy register row alignment

The approved Privacy HTML keeps a processing-activity table at 768px; the
container-responsive runtime turns it into tall labelled cards. Use the shared
viewport-responsive table contract and compact its existing padding token at
tablet widths. Keep the actual data-subject, lawful-basis, review, owner and
status fields and the visible detail action. Below the shared phone breakpoint,
retain labelled cards. Unusually narrow tables or long unbreakable values may
still require the existing table viewport's horizontal scrolling.

Compare source and runtime at 1440, 1280, 1024, 768 and 390px, in both runtime
themes; test filter, detail, history, denied and empty paths. The sample HTML's
review statuses and unsupported Privacy collections are not runtime facts.
This is partial V2 layout integration, not whole-screen acceptance.
