# V2.10 Key indicators

The register reads `/api/v1/risk-indicators` using the existing authorized, scoped population endpoint. It renders the returned indicator state and explanatory reason, native observation, approved limit, observation date and configured freshness limit. Stale and incomplete results remain unknown even if a previous observation or threshold is displayed. Search covers only loaded rows; the type filter is sent to the server. Pagination and incomplete reads are explicit, and no totals or observation actions are invented.
