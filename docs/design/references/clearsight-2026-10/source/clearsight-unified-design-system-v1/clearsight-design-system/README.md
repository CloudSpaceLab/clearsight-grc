- `clearsight-design-system-4k.png`: light reference, 3760 × 2740.

- `clearsight-design-system-mobile.png`: full mobile reference, 780 × 10758.
- `clearsight-design-system-spec.md`: implementation ownership, contracts, state matrix and screen-to-component mapping.
- `clearsight-design-system.html`, `system.css`, `system.js`, `assets/`: modular source of the reference only; **not a production component library**.

The reference uses illustrative records only. No Live ClearSight API, scoring, authority or customer data is connected. Production implementation must reuse the existing React `components/ui` contracts, design tokens and governed service boundaries.
