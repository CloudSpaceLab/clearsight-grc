# Privacy register table boundary

The V2 Privacy register retains its table at tablet widths and switches to
labelled records at 700px. At 701px the first action extends beyond the table
viewport because the identity column retains a 140px minimum. Reduce that
minimum to 128px only between 701px and 740px; preserve all fields, wrapping,
44px action targets and the existing phone replacement. Verify the source and
runtime at the approved widths, the 700/701px boundary, long names, details,
filters and empty/denied states. This is partial V2 layout integration, not
whole-screen acceptance.
