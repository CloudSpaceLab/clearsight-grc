# Processing activity details

The activity detail presents recorded data categories, recipients and transfer basis, systems and named reviews. Missing reviewer names remain unavailable instead of exposing principal identifiers. The underlying scoped activity read remains the source of the values.

The 1440, 768 and 390 pixel renders in `docs/evidence/2026-11-22-privacy-details/` were generated from a mocked API and isolated component. They were inspected for the new sections and overflow. They do not establish full-shell layout, production permissions or populated-bank data quality; at desktop/tablet the isolated main content retains the shell's empty sidebar offset.
