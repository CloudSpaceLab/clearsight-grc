# Framework Library inspector proportion

The approved Framework Library places a 340px edition inspector beside the
register at 1440px and 1280px. The runtime used 394px, leaving the register
narrower than the source and crowding edition details. Limit the existing
inspector column to 340px at these widths. Preserve its compact breakpoint,
the mobile sheet, explicit selection, provenance and rights checks.

Compare the pinned source and runtime at all five approved widths, in both
runtime themes, and verify selected and unselected edition states, keyboard
selection, filters and overflow. This is partial layout integration; catalog
and operational acceptance remain separate.
