# Forms V2.3 walkthrough

1. Open Forms and choose Edit on Branch control self-assessment.
2. Click a question title, hint or option to edit it in place. Required is on the question footer.
3. Scroll to the rating grid. Edit its row names and choice headers directly; add a row or a choice.
4. In the mixed-type table, click a column heading to rename it, or its type badge to edit that column.
5. Use Automated check, then choose the measurement, endpoint and threshold. Advanced quality policies are under Data quality & reliability.
6. Test with sample data to see a synthetic result. Save, Preview and Publish remain separate operations.
7. Existing form versions assigned to programs stay pinned. Changing the navigation scope does not reassign a submitted assessment.

Run the risk workflow separately: Risk & Losses → select branch → select department → select unit. The summary, breakdown, risk register and loss exports now use the same stable scope identity. Clear selectors to include all descendants again.
