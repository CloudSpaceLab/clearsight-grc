# V2.9 UI/UX audit and completion

The audit covered the delivered package's loss, control, RCSA, risk, vendor, form, assessment, evidence, privacy, Work, Inbox and report handoffs. It focused on whether an operator can prepare, save, submit, review, return, correct and find the next accountable action.

| Observed gap | Implemented outcome |
| --- | --- |
| Loss form captures too little source context | Four-step capture with 18-field mapping, optional risk link, explicit period and source context. |
| Losses book immediately; recoveries directly reduce net | Independent acceptance and received-recovery verification, retained reversals and reviewed closure. |
| Spreadsheet repeats inflate events | Mapping/duplicate/period preview and draft-only CSV import. |
| Risk workspace adds currencies and unaccepted losses | Reviewed NGN summary, original-currency event rows and exclusion labels. |
| Controls lack lifecycle and exact scope | Scoped editor, saved drafts, sampled testing, independent conclusions and correction work. |
| RCSA work is lost or reviewed against a changed basis | Saved drafts/resume, frozen membership and control/evidence/rating guards. |
| Vendor activation is a one-way modal | Reviewed activation, periodic review, suspension, resumption and verified exit. |
| Forms have no correction cycle | Immutable submitted cycle and linked correction/resubmission. |
| Evidence changes request has no replacement path | Targeted refresh and independent supersession with exact versions. |
| Approval preparation disappears on navigation | Saved draft/resume/cancel and overwrite protection. |
| Closed privacy cases cannot be reopened responsibly | Reasoned reopening with retained closure history. |
| Work completion lacks source checks or useful verification | Actor/scope/source validation, substantive outcome and independent loss/KRI verifier. |
| Returned reviews vanish from actionable work | Exact-source owner Work rows, Inbox alerts and replacement links. |
| Loss report does not answer management questions | Concentration, recognition lag, unrecovered aging, cash receipts/reversals, prospects and source drilldown. |

Pinned evidence is accessible before a decision. Financial review shows the actual submitted snapshot; receipt review shows amount, date and source. Returned closure rationale stays visible and prefills resubmission. Working identity and organizational context remain explicit. Responsive layouts, semantic labels, focus styles, print styles and meaningful unavailable-record states are supplied; visual/browser verification remains outstanding.
