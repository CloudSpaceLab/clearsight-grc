## Environment and exclusions

Python Playwright + Chromium loaded the self-contained HTML with `set_content`. Metadata persistence was tested with a labelled localStorage test double. Upload byte handling exercised the browser's session fallback. Native `file://` navigation returned `ERR_BLOCKED_BY_ADMINISTRATOR`; the combined file-opening/native-storage/download group remains Blocked, not Pass.

CSV/JSON payloads and source bytes were tested, but native download delivery, system printing and browser PDF viewing were not verified. No live model, bank API, external signing provider, malware service, production authentication, concurrency or actual notification was tested. Firefox/Safari, a complete WCAG/screen-reader audit and production-scale performance are not certified.

A combined parallel test invocation exceeded its execution time budget. The affected suites were subsequently rerun to completion individually; only completed final result files are included in the totals. Raw results are in `tests/`.
