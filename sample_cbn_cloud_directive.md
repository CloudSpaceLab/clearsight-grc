# Central Bank of Nigeria (CBN) 
## Guidelines on Cloud Computing for Financial Institutions
**Date:** August 12, 2026
**Reference:** FPR/DIR/CIR/GEN/01/050

### Section 1: Introduction
1.1. These guidelines establish the minimum standards for financial institutions operating in Nigeria regarding the adoption and use of cloud computing services.

### Section 2: Data Residency and Sovereignty
2.1. All customer personally identifiable information (PII) and core banking transaction data must reside on servers physically located within the borders of the Federal Republic of Nigeria.
2.2. Financial institutions may use offshore cloud infrastructure only for non-core, non-sensitive operational data, subject to prior written approval from the CBN.

### Section 3: Security and Access Control
3.1. Financial institutions must implement Multi-Factor Authentication (MFA) for all administrative access to cloud environments.
3.2. Data stored in the cloud must be encrypted at rest using industry-standard AES-256 encryption or higher.
3.3. Financial institutions must conduct independent penetration testing on all cloud-hosted external interfaces at least once every six (6) months.

### Section 4: Incident Reporting
4.1. Any suspected or confirmed data breach involving cloud infrastructure must be reported to the CBN Director of Banking Supervision within 72 hours of discovery.
